## 0. 一句话

`frontend/packages/ui/src/lib/cn.ts` 的 `twMerge` 不认识本项目的**语义字号档**
（`text-body-sm` 等），把它与 `text-<颜色>` 判成**同一组** ⇒ 颜色赢 ⇒ **字号类被删**、
字号静默回落到继承值。已用 `extendTailwindMerge` 登记 10 个语义档修掉；
判据 `verify_typography.py` 同步改为**读项目自己的 merge 配置**。

**结果**：缺陷 **86 → 28 → 0**，棘轮**收到 0**；四端渲染证据齐（T3b **1030 对**零不一致）；
像素基线已刷新并**自洽**（16/16 全 0）；**全量门禁复跑全绿**（`RUNNER_EXIT=0`）。
本存证覆盖**六步**：§1–§7 第一步（改 `cn.ts` + 判据同步）· §8 第二步（28 条 T2）·
§9 第三步（幽灵依赖）· §10 第四步（四端渲染）· §11 第五步（基线刷新）·

## 8. 【第二步】顺着 ① 浮出的 28 条 T2 真缺陷 —— 已分诊并修掉（2026-09-24 同日）

用户裁定：**4 条新 T2 真缺陷 = 产品该改**。分诊后发现**不是 4 条、而是 28 条同根因**。

### 8.1 分诊

同一把尺子下取「修后才出现」的差集（`_t2_new_defects_2026-09-24.txt`）：

    修后才出现（此前被 cn() 吞掉而不可见）4 条：
      im/app/(app)/chat/page.tsx:876
      web/app/(app)/billing/page.tsx:246
      web/app/(app)/contract-review/ResultView.tsx:438
      web/app/(app)/contract-review/ResultView.tsx:453
    修前有、修后没有：**0 条**（⇒ 修法没有改变任何既有判定 ✓）
    修后 T2 按端：admin 4 · im 3 · lawyer 8 · web 13 = 28

🚨 **28 条形状完全相同**：`text-body-sm`（或 `text-body`）+ `leading-relaxed` → 实测比 **1.625**。

### 8.2 根因（**先核实再动手**）

产物 CSS 实测（四端 `apps/<app>/.next/static/css/app/layout.css`）：

    .text-body-sm   { font-size: 13px; line-height: 1.65 }   ← 自身就带**正确**行高
    .text-body      { font-size: 14px; line-height: 1.7  }
    .leading-relaxed{ line-height: 1.625 }                   ← **低于**规范 §3.3 规则 2 的地板 1.65

⇒ `text-body-sm leading-relaxed` 是**用更差的值覆盖了正确值**（1.65 → 1.625）。
规范地板 1.65 == `body-sm` 的声明行高 ⇒ 删掉冗余的 `leading-relaxed` 即回到**设计系统声明的值**。

### 8.3 为什么**不**改 preset 的 `lineHeight.relaxed`（另一条路）

全仓库 `leading-relaxed` 共 **43 处**，其中 **28 处**与正文档字号类同串（= 违规），
另 **15 处**用在**非正文档**上（1.625 合法）。改 preset 会**连带把那 15 处也改掉**（43 处全变），
而逐点删只动真正违规的 28 处。且**复发会被 T2 抓住**（T2 就是这条判据）⇒ 不需要额外门禁。

### 8.4 执行与验证

- 干跑报告：**28 处全部是「同串内 `text-body* leading-relaxed`」**、**条件式 0 条**
  ⇒ 纯 token 移除安全（脚本守卫：只在**同一个引号串**内同时含两者时才删）。
- 落盘：`_t2_fix_applied_2026-09-24.txt`（28 处 before/after 逐条留痕）。
- 复核：`className=""` **0 处**（没把类名删空）；残留「同串违规」**0 处**。
- 判据复跑：**缺陷 0 条 · EXIT=0**（`_typography_after_t2fix.log`）。
  ⚠️ 判对数 **34 → 6**（28 对违规组合已不存在）—— **不是覆盖率退步**，已在棘轮注释里写明。
- 棘轮：`StaticGate("--source-only", 0, 0, "declared", …)` ⇒ **零容忍**（任何回归立刻红）。

**总账**：缺陷 **86 → 28 → 0**。这是本项目排印门禁第一次**清零**。
