③ 根因实测：tailwind-merge 把**自定义字号**当成 text-color，吞掉语义文字色
────────────────────────────────────────────────────────────
$ node -e "const {twMerge}=require('tailwind-merge'); console.log(twMerge(...))"
  ["text-info-600","text-caption"]                => "text-caption"
  ["text-danger-600","text-label"]                => "text-label"
  ["text-ink-500","text-label"]                   => "text-label"
  ["text-white","text-body-sm"]                   => "text-body-sm"     ← #42 同根
  ["text-info-600","text-caption","text-ink-700"] => "text-ink-700"
  （反向 "text-caption","text-info-600" => "text-info-600" ⇒ **顺序敏感**）

Badge.tsx:82-87 的调用顺序是
    cn("inline-flex … rounded-r1", variantStyles[key], sizeStyles[size], className)
  ⇒ `sizeStyles` 里的 `text-caption`/`text-label`/`text-body-sm`
    排在 `variantStyles` 的 `text-info-600` **之后** ⇒ **被顶掉**。

实测印证：DOM 上**根本不存在** `text-info-600` 这个 class ——
一个 info 变体徽章的 class 是
    inline-flex items-center whitespace-nowrap border font-medium rounded-r1
    bg-info-500/15 border-info-500/30 px-1.5 py-0.5 text-caption gap-1
                                                      ↑ 只有字号，没有颜色

⇒ **Badge 的文字色通道整体失效**，文字色退化为**从容器继承**。
  这是 **#42 的第二个受害组件**（第一个是 Button 的 `text-white`），
  影响面比 Button 大得多：26 页里 **82 个可识别变体的 Badge 全部失败**。

────────────────────────────────────────────────────────────

⑧ 附：一次**被我撤回的假红**（`cursor:pointer` ≠ 可键盘到达，但也 ≠ 缺陷）
────────────────────────────────────────────────────────────
审计中撞见：`lawyer /cases` 的表格行是裸 `<tr>`（无 `<a>`/`role`/`tabindex`，
`tabIndex=-1`），但 `cursor:pointer` + `hover:bg-brand-50`，且点击确实导航
（实测 URL `/cases` → `/cases/8`）。而 `verify_focus_ring.py` 的 `FOCUSABLE`
选择器只挑「按 DOM 语义可聚焦」的元素 ⇒ **结构上看不到它**。

一度准备报成「键盘不可达」缺陷（WCAG 2.1.1）。**实测后撤回**：
该页面的**案号列是一个 `<button>`**（`<button>HLW-DEMO-0008</button>`），
点击它同样导航（实测 `/cases` → `/cases/8`）⇒ **键盘路径存在**，
`<tr>` 的 `cursor:pointer` 只是**鼠标便捷路径**。

对照组（证明判据不是「只会红」）：
  web /documents 0 个 · admin /cases 0 个 · im /cases 0 个 · lawyer /cases 4 个
  输出见 evidence/kbd_reach_probe.txt

教训：**`cursor:pointer` + 不可聚焦 ≠ 缺陷** —— 它可能只是鼠标便捷路径，
键盘路径由**另一个**可聚焦元素提供。判据若不识别「等效的可聚焦入口」，
就会把正确实现报成缺陷。这与「判据必须认识项目自己的补偿机制」（§8.3 的
`min-h-tap`）同族，是该纪律的**第 7 次复发**。
