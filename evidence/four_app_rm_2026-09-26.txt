### 这次运行对 #75 的三条具体意义

1. **R1c 升为判红后不红** —— 若 reduce 档下真有内置旋转类在跑，这里必须 rc=1。
   实测 rc=0 ⇒ **「升为判红」不是纸面动作**（同一批判据在真页面上跑过）。
2. **加载态 8 组全绿** —— 加载态是 `<Spinner>`（`spin-soft`）+ 骨架屏（`pulse-soft`）**唯一出现**的地方，
   `reduce=0` 证明两者都被令牌停下（这正是「归零静止」要的效果）。
   对照：改动前同一门禁在这里抓到 **im 骨架屏 2 组红** + **R1c 4 处只报不判**（lawyer / admin 的 spinner）。
3. **R2 覆盖新令牌** —— 输出里 `声明值` 一行含 `--dur-spin`=0ms、`--spin-iter`=1
   ⇒ 新令牌的归零在**运行时**被断言，不只是静态比对。

## 附：编排脚本源码（可复现口径）

下面这份**不是**仓库里的登记脚本 —— 它是本次运行用的**临时编排**（`%TEMP%\run_rm_all.py`）。
贴在这里是为了**可复现**：它复用 `evidence/run_browser_job.py` 的生命周期函数，
**刻意不往 `JOB_SPECS` / `CI_JOB_PROBES` / `ci.yml` 登记任何 job**
（新增 `browser-all` job 属**待拍板**；登记了就等于绕过拍板）。

⚠️ 放在 `evidence/` 下的 `.py` **必须登记**，否则门禁判据 0 **当场判红**（坑 46）
⇒ 所以它是**文本**，不是可执行文件。

```python
# -*- coding: utf-8 -*-
"""临时四端实测编排 —— **#75 运行时验证**（reduce 档下动效行为）。

**为什么必须跑真判据**：
  #75 把 33 处内置旋转类收敛进 `<Spinner>`（走新令牌 `--dur-spin` / `--spin-iter`），
  并把 `verify_reduced_motion.py` 的 **R1c 由「只报不判」升为判红**。
  源码级判据（`verify_motion_tokens.py` 的 A4 / R7）只能证明「源码里没有内置旋转类」，
  **证不了「reduce 档下真的停住了」** —— 那是运行时的事，只能真跑。
  ⇒ 这是「R1c 升级后门禁会不会当场变红」的**唯一**验证手段。

顺带回归：#75 改了 25 个文件的渲染（含按钮内图标），把 #72/#39 的两条判据一并复跑。

⚠️ 本脚本**只在临时目录**读写；库是隔离的 `all.db`，收尾整目录删掉。
⚠️ **不往 `JOB_SPECS` / `CI_JOB_PROBES` / `ci.yml` 登记任何 job**（新增 `browser-all` 属待拍板）。
"""
import contextlib
import importlib.util
import pathlib
import shutil
import sys
import tempfile

ROOT = pathlib.Path(r"C:\Users\RS\Documents\trae_projects\NLawer")
RBJ = ROOT / "evidence" / "run_browser_job.py"

spec = importlib.util.spec_from_file_location("rbj", RBJ)
rbj = importlib.util.module_from_spec(spec)
spec.loader.exec_module(rbj)

with contextlib.suppress(Exception):
    sys.stdout.reconfigure(line_buffering=True)

APPS = ("web", "lawyer", "admin", "im")
# (探针, 额外参数)。`verify_reduced_motion.py` **不传 `--app`** ⇒ 它内部的 APPS
# 表会**四端全扫**（含加载态采样 —— 那正是 `spin-soft` 唯一会出现的地方）。
PROBES = (
    ("verify_reduced_motion.py", ()),
    ("verify_breakpoints.py", ()),
    ("verify_adjacent_targets.py", ()),
)

tmp_root = pathlib.Path(tempfile.mkdtemp(prefix="nlawer-rm-all-"))
log_dir = tmp_root / "logs"
log_dir.mkdir(parents=True, exist_ok=True)
db_path = tmp_root / "all.db"
env = rbj._backend_env(db_path, APPS)

print("=" * 76)
print("四端实测 · #75 运行时验证（临时编排 · 不登记任何 job）")
print(f"  隔离库：{db_path}")
print(f"  日志：{log_dir}")
print("=" * 76)

services = []
exit_code = 2
try:
    missing = [a for a in APPS
               if not (rbj.FRONTEND / "apps" / a / ".next" / "BUILD_ID").exists()]
    if missing:
        print("缺生产构建产物：", missing)
        raise SystemExit(2)

    if not rbj._seed(db_path, env):
        print("灌种子失败")
        raise SystemExit(2)

    be = rbj._start_backend(env, log_dir)
    services.append(be)
    if not rbj._wait_http(f"{rbj.API_BASE}/api/health/readyz", rbj.READY_TIMEOUT_SEC, be,
                          "后端 readyz（真 DB 往返）"):
        print("后端未就绪")
        raise SystemExit(2)
    print("  OK 后端就绪（readyz 200）")

    node = rbj._check_node()
    for a in APPS:
        fe = rbj._start_frontend(a, node, log_dir)
        services.append(fe)
        if not rbj._wait_http(f"http://localhost:{rbj.APP_PORTS[a]}/", rbj.PAGE_TIMEOUT_SEC, fe,
                              f"{a} 首页"):
            print(f"{a} 未就绪")
            raise SystemExit(2)
        print(f"  OK {a} 就绪（http://localhost:{rbj.APP_PORTS[a]}）")

    print()
    print("=" * 76)
    print(f"跑 {len(PROBES)} 条真判据（四端）")
    print("=" * 76)

    worst = 0
    for name, extra in PROBES:
        rc, sec, out, err = rbj._run_probe(name, extra, env)
        icon, meaning = rbj._RC_MEANING.get(rc, ("?", f"未知退出码 {rc}"))
        print(f"\n>>> python evidence/{name} {' '.join(extra)}")
        print(f"  rc={rc} · {meaning} · {sec:.1f}s")
        if out.strip():
            # ⚠️ 用 ascii() 转义打印：本机终端是 GBK，探针 stdout 是 UTF-8，
            #    直接 print 会把含 ✓/✗ 的**整行**变成不可逆乱码。
            print("  -- stdout（尾 120 行 · ascii 转义）--")
            for x in out.strip().splitlines()[-120:]:
                print("    " + ascii(x))
        else:
            print("  -- stdout 为空 --")
        if err.strip():
            print("  -- stderr（尾 40 行 · ascii 转义）--")
            for x in err.strip().splitlines()[-40:]:
                print("    " + ascii(x))
        if rc == 1:
            worst = max(worst, 1)
        elif rc != 0:
            worst = max(worst, 2)
    exit_code = worst
finally:
    for s in reversed(services):
        with contextlib.suppress(Exception):
            s.stop()
    print("\n-> 服务已收尾")
    shutil.rmtree(tmp_root, ignore_errors=True)
    print(f"-> 临时目录已删：{tmp_root}")

print(f"\nEXIT={exit_code}")
raise SystemExit(exit_code)
```
