## 核心结论速览

- **诊断**：9 个结构性问题，其中 `theme/colors.ts` 的 `emerald/teal/cyan` 键名与色值完全错位属功能性缺陷
  （`KpiCard color="emerald"` 渲染出蓝色）；且**全部 4 个应用都未考虑移动端**。
- **主张**：品牌主色由 `#4F46E5` 下沉为 `#274C93`（同色相，明度降 34%），去掉 `indigo→cyan` 渐变；
  圆角由 12/16/24px 收敛为 4/6/8/12px。
- **最大提升点**：把 PRD 的「AI 生成 / 律师确认」责任边界，从一条紫边线升级为完整的三态视觉系统 + 全局图例。
- **最大结构改动**：四个应用统一到同一个 AppShell（桌面 240px 侧栏 + 56px 顶栏 / 移动底部 Tab Bar），
  替代当前「大卡片门户 + 各自为政的 header」。
- **移动端立场**：移动优先，但**不是所有页面都移动化**。im 与 web 改为以 375px 为设计基准起草；
  lawyer 新增 4 个移动专属形态（含相机拍照举证、弱网离线可读 + 待同步队列）；admin 仅提供只读移动视图。
- **工作量的 60%** 在基础设施（Token 化、组件层、深色模式变量化），页面重构占 40%；
  移动端追加要求额外带来 8 个移动组件与弱网离线能力（需后端配合）。
